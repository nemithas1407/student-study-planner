📚 Student Study Planner

📌 About the Project
Student Study Planner is a simple and responsive web application developed using HTML, CSS, and JavaScript. It helps students organize their study schedules, manage daily tasks, track assignments, and plan their learning activities effectively.

✨ Features
- Add and manage study tasks
- Set task deadlines and priorities
- Organize daily study schedules
- Mark tasks as completed
- Delete tasks when they are no longer needed
- Track study progress
- Simple and user-friendly interface
- Responsive design for desktop and mobile devices

 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage

 🚀 How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Add your study tasks and organize your schedule.

📂 Project Structure
- `index.html` – Website structure
- `style.css` – Styling and responsive design
- `script.js` – Task management and application functionality

🎯 Project Objective
The main objective of this project is to help students manage their study time efficiently, stay organized, complete assignments on time, and improve productivity.
